## H1 — class N(Δ, τ, γ) and the definition of Δ_max (2026-11-09, rev. r1 2026-11-10)

**Hypothesis.** (2) constrains only m = E_π δ; fixed γ admits Bessel m, all γ ≤ γ₀ forces m ≡ const; without a budget Δ_max = ∞.
**Verdict: confirmed in a refined form.** Structural claims proven for bounded measurable δ with (2) read for a.e. x (choice of reading changes no result); the Fourier description is global (ℝ^d). Refinements: two radii with γ₁/γ₂ ∉ {j_k/j_l} already force m ≡ const (proven on ℝ^d; local version cited), but a second radius above γ₁ is quantitatively almost blind for large d; if idle rounds are free, τ drops out of the problem.
**Main formula (expectation variant; γ ≤ ε/(4M)).** Batched ZO-SGD with burn-in: T(Δ) = ⌈36.25 M²R²/ε²⌉(⌈2d²/(d−1) + (2d+8τ−3)dΔ²/(M²γ²)⌉ + τ⌈log₂(16R√dΔ/(γε))⌉₊) = O(Δ²) ⇒ Δ_max = ∞ without budget for the all-radii class (unconditional) and for the fixed-radius class with γ ≤ ε/(4M); nothing proven for fixed γ > ε/(4M). Δ_max(T) ≥ (εγ/R)√(T/(74.5(2d+8τ−3)d)) for T ≥ 2T₁, i.e. T ≳ τ(MR/ε)² log: the first branch of H2's lower half, outside the regime τ ≳ T. Δ_cp(C) ≥ Mγ/√(2d+8τ−3) for C ≥ (149/4)(6 + t₀/d): the lower side of the expected picture only. Probability variant: ε → βε (Markov).
**Numerics.** E1.1, E1.3, E1.4 (5 seeds): zeros at MC level, off-zero bias = ΔtΨ_d(t)/d; second-radius bias = Δ|ω||Ψ_d(γ₂|ω|)|; batched second moment exact to 1.41%, additive in d and τ. **Implications.** A non-degenerate threshold is Δ_max(ε,β;d,τ;T) with q-query rounds, one chain step per round, idle rounds charged, exogenous chain; in the all-radii class "E_π δ = const a.e." (⇔ (2) for all γ ≤ γ₀) γ moves to the algorithm; the expected picture Mγ/√d is about Δ_cp = Δ_max(C·T₀). H6 supported by Prop.
